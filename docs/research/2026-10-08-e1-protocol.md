# E1 pilot frozen protocol

Frozen before the full pilot on 2026-10-08. This expands the approved E0/E1 plan; no results from the full pilot have been inspected.

21 models: seeds 1/2/3, L0 reward-only weight0, L1 exposed synthetic continuous-feedback weights1/10/100, U1 privileged all-item-score weights1/10/100. Training3000 episodes,40 epochs,batch512; fixed catalog200 items,K5,horizon20,lt3,div0.8,pairwise head,latent64. Validation/test128 behavior episodes per split.16 evaluation users per seed; full episode and shared5-step behavior prefix. Five planners,nominal proposal budget512,depth2,beam3.

Select one global weight for L1 and one for U1 by the mean validation common-prefix sid_hier return across the three seeds. Tie break: lower weight. Do not select weights per seed or inspect test scores for selection. Retain all pilot results. This is selection for the proposed planner; report other planners under the same selected model rather than choosing a model separately for each comparator.

Primary comparisons on frozen selected models: sid_hier minus flat_uniform,flat_policy,sid_flat; L1 minus L0 and U1 minus L1 under each fixed planner. Complete and common-prefix returns are reported separately. Common-prefix tail uses the original episode discount. Primary independent replication unit is training/log seed, with paired users within a seed. Hierarchical paired bootstrap: resample seeds then user IDs within each sampled seed;10000 draws,analysis RNG seed20261008,95% percentile intervals. Three-seed intervals are exploratory. Confirm selected L0/L1/U1 with seeds4/5 (at least5 total); if training protocol changes, rerun all groups rather than merge unequal budgets. Ten-seed confirmation is reserved for boundary/small effects, not repeated significance seeking.

Seeds are explicit and evaluation seed blocks do not overlap across split/run/user. Same condition seed shares observations and prefix histories across weights and methods. Different runs vary logging/model/search/evaluation streams; catalog and underlying user population remain fixed. Generalization here is to independent trajectories in that population, not unseen users or catalogs.

Checkpoint,source hashes,full configuration,per-epoch losses,per-user returns,logged/closed-loop score ranks,actual slate/score calls and planner latency are saved. GPU timing uses a separate warmup planner,then synchronizes before/after measured planning. Diagnostics and history encoding are outside planner latency; total evaluation wall time is also saved. GPU5 shares a machine with other experiments; latency is descriptive until isolated benchmarks are run.

This pilot does not enforce a hard total-operation budget; nominal budget allocation is inherited from Gate3 and actual calls are reported. It does not demonstrate performance on real clicks. Synthetic feedback is served-item unary response plus independent noise std0.02; pairwise reward is supervised only by observed scalar reward. Further coverage,click/position models,E2-E6 and hard-budget comparisons remain necessary for the paper.
