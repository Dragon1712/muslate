# R2-A exploratory protocol (frozen before execution)

This additive experiment preserves frozen E1 code and results. It conditions on existing L0 (w_score=0) and L1 (w_score=100) checkpoints, each with training seeds1–5. It does not retrain, select new weights, claim confirmation, or claim equal compute. The 40,000,000 trajectory region is reserved and unused.

Closed loop: 80 cells = 2 conditions × 5 training seeds × 2 proposals × depths0/1/2/3. Nominal B=128, beam=3, original16 existing users, original simulator settings from checkpoint, deterministic/noiseless execution. Prefixes use fresh exploratory offset30,000,000+2,000×training_seed and shared5-step behavior prefix, paired across conditions/proposals/depth for a seed. Depth denotes additional future actions; horizon is depth+1 capped at remaining episode steps. This is a fixed nominal proposal curve, with different actual costs across depths/proposals. Flat uniform128; SID uses existing B128 allocation sampled34,out34,widen4,refine5,fine_per_position3. Each closed-loop decision includes actual proposal generation/refinement in timing and counters.

Random streams: SHA256(decision_key, ordered ancestor action tuples), not depth, beam rank or recursion traversal. Decision key =30,000,000+100,000×training_seed+100×user_id+t. The root seed is independent of depth/beam. Closed-loop states diverge after different actions; only identical observation states may be claimed to share a root candidate pool.

Fixed observation probes: first4 users per checkpoint/proposal, at exactly the shared prefix endpoint. Cache the exact root array; reuse it for depth0/1/2/3 beam3 and depth1 beam3/8/16. Record cache generation cost separately, and per-search cost excluding the cache. Evaluate every cached root's two-step value using its full action-addressed successor candidate pool (no successor pruning at depth1). Beam3/8/16 are exact subsets of this candidate-scope reference; report immediate rank of reference best, exclusion and model-value regret. This is not a global200-item Oracle. Truth reward is evaluated after learned choice only and never enters learned search.

Small diagnostic:4-item,K2,H3 environment, all12 ordered legal slates, exact enumeration of all12^3 sequences, compare myopic and beam3/8/12, depth2 with true dynamics. Oracle has hidden-state information and is only a mechanism/search diagnostic. It is separate from learned200-item results.

Artifacts bind all imported MuSlate source, new R2 scripts/protocol, checkpointSHA, original training identities and runtime information. Record each executed slate/reward, sequence prediction, root identity, actual reward-only/joint-transition/item-score/proposal/refinement counts, synchronous perGPU serial latency (mean,p50,p95), and belief encoding separately. GPU parallelism is across seeds; no final controlled crossGPU latency claim. Replay every observed action/reward and discounted return. Report full expected matrix and failures/missing cells; no suppression of failed jobs.

Statistics: mean per-user paired depth-minus0 effect per training seed, then primary Student-t95% interval across5 independent seed means (df4,t=2.776445). Supplementary paired hierarchical bootstrap10,000 replicates (seed20261009): sample5 seeds with replacement, then sample paired users with replacement within each selected seed; percentile2.5/97.5 bounds. Both intervals are reported without choosing the favorable one. User decisions are not independent training replicates. This protocol includes only shared-prefix evaluation, not full-episode robustness, equal-budget calibration curves, multistep prediction/re-encoding diagnostics,64-user confirmation, model ablations or Adaptive-H.

Execution gate: targeted determinism/horizon/exhaustiveOracle tests, then1-user smoke at all8 proposal/depth combinations for each condition (16 smoke cells), then full80-cell matrix. Source protocol hash must be fixed before the smoke; runtime failures are recorded and reported.
